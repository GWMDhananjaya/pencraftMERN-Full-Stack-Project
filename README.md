<h1>Pencruft - Blog Post Website</h1>

<h3>Pencruft is a modern blog post website built using **React** for the frontend and **Node.js** for the backend. It allows users to create, edit, and share blog posts with a clean and intuitive interface.</h3>

https://github.com/user-attachments/assets/4a252b9e-b090-4635-bf28-3b2c25df7dd2

<h5>Features</h5>
<ul>
<li>User authentication (login/signup)</li>
<li>Create, edit, and delete blog posts</li>
<li>View all published posts</li>
<li>Responsive design</li>
<li>RESTful API for managing posts and users</li>
</ul>


<h5>Technologies Used</h5>

  <ul>
<li>**Frontend**: React, React Router, Axios</li>
<li>**Backend**: Node.js, Express.js</li>
<li>**Database**: MongoDB (or any other database you are using)</li>
<li>**Authentication**: JSON Web Tokens (JWT)</li>
<li>**CSS Framework**: Tailwind CSS (or any other you are using)</li>
  
</ul>
